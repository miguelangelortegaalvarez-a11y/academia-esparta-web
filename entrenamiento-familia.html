APUNTES ELITE: DERIVADAS

Formación para Guerreros Matemáticos - Academia Esparta

1. Constantes y Potencias

$f(x) = k \implies f'(x) = 0$
$f(x) = x^n \implies f'(x) = n \cdot x^{n-1}$
GUERRERO BASE
$f(x) = 7x^3$
$f'(x) = 7 \cdot 3x^2 = \mathbf{21x^2}$ 		GUERRERO ÉLITE
$f(x) = \frac{5}{x^4} = 5x^{-4}$
$f'(x) = 5(-4)x^{-5} = \mathbf{-\frac{20}{x^5}}$

2. Raíces (Potencia de exponente fraccionario)

$f(x) = \sqrt[n]{x} \implies f'(x) = \frac{1}{n \cdot \sqrt[n]{x^{n-1}}}$
GUERRERO BASE
$f(x) = \sqrt{x}$ (Raíz cuadrada)
$f'(x) = \mathbf{\frac{1}{2\sqrt{x}}}$ 		GUERRERO ÉLITE
$f(x) = \sqrt[3]{x^2} = x^{2/3}$
$f'(x) = \frac{2}{3}x^{-1/3} = \mathbf{\frac{2}{3\sqrt[3]{x}}}$

3. Exponenciales y Logaritmos

$f(x) = e^x \implies f'(x) = e^x$
$f(x) = \ln(x) \implies f'(x) = \frac{1}{x}$
GUERRERO BASE
$f(x) = 5e^x$
$f'(x) = \mathbf{5e^x}$ 		GUERRERO ÉLITE
$f(x) = \log_2(x)$
$f'(x) = \mathbf{\frac{1}{x \ln 2}}$

4. Funciones Trigonométricas

$(\text{sen } x)' = \cos x$
$(\cos x)' = -\text{sen } x$
$(\text{tg } x)' = 1 + \text{tg}^2 x = \frac{1}{\cos^2 x}$
GUERRERO BASE
$f(x) = 3 \text{ sen } x$
$f'(x) = \mathbf{3 \cos x}$ 		GUERRERO ÉLITE
$f(x) = \frac{\cos x}{2}$
$f'(x) = \mathbf{-\frac{\text{sen } x}{2}}$

5. Regla de la Cadena (La Joya de la Corona)

"Derivada de lo de fuera, manteniendo lo de dentro, por la derivada de lo de dentro".

$f(x) = g(h(x)) \implies f'(x) = g'(h(x)) \cdot h'(x)$
GUERRERO BASE
$f(x) = (3x^2 + 1)^5$
$f'(x) = 5(3x^2 + 1)^4 \cdot (6x) = \mathbf{30x(3x^2 + 1)^4}$ 		GUERRERO ÉLITE
$f(x) = \text{sen}(e^x)$
$f'(x) = \cos(e^x) \cdot e^x = \mathbf{e^x \cos(e^x)}$
