Ecuaciones de 2º Grado: Resolución Detallada y Narrativa

1. ECUACIONES COMPLETAS: a x2 + b x + c = 0

Ejemplo 1: Dos soluciones reales

Ejercicio: x2 - 5x + 6 = 0
\(a = 1, b = -5, c = 6\)
Identificamos los valores: a (acompaña a x²), b (acompaña a x) y c (número suelto).
\(x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 1 \cdot 6}}{2 \cdot 1}\)
Sustituimos en la fórmula general. El negativo de -5 se convierte en positivo.
\(x = \frac{5 \pm \sqrt{25 - 24}}{2}\)
Calculamos la potencia \((-5)^2 = 25\) y la multiplicación \(4 \cdot 1 \cdot 6 = 24\).
\(x = \frac{5 \pm \sqrt{1}}{2} \implies x = \frac{5 \pm 1}{2}\)
Restamos dentro de la raíz y calculamos su valor (\(\sqrt{1} = 1\)).
\(x_1 = \frac{5+1}{2} = 3 \quad | \quad x_2 = \frac{5-1}{2} = 2\)
Separamos los dos caminos (+ y -) para obtener las dos soluciones finales.
RESULTADO: x = 3, x = 2

Ejemplo 2: Una solución única (Doble)

Ejercicio: x2 - 4x + 4 = 0
\(a = 1, b = -4, c = 4\)
Extraemos los coeficientes de la ecuación para usarlos en la fórmula.
\(x = \frac{-(-4) \pm \sqrt{(-4)^2 - 4 \cdot 1 \cdot 4}}{2 \cdot 1}\)
Colocamos los valores en la fórmula. El -b cambia el signo de -4 a +4.
\(x = \frac{4 \pm \sqrt{16 - 16}}{2}\)
Calculamos el cuadrado \((-4)^2 = 16\) y el producto \(4 \cdot 1 \cdot 4 = 16\).
\(x = \frac{4 \pm \sqrt{0}}{2} \implies x = \frac{4 \pm 0}{2}\)
Al restar obtenemos 0. La raíz de 0 es 0, por lo que sumar o restar no afectará al número.
\(x = \frac{4}{2} = 2\)
Dividimos el resultado entre 2. Obtenemos una única solución repetida.
RESULTADO ÚNICO: x = 2

Ejemplo 3: Sin solución real

Ejercicio: x2 + 2x + 5 = 0
\(a = 1, b = 2, c = 5\)
Anotamos los valores de a, b y c para la sustitución.
\(x = \frac{-2 \pm \sqrt{2^2 - 4 \cdot 1 \cdot 5}}{2 \cdot 1}\)
Sustituimos. En este caso b es positivo, así que -b será -2.
\(x = \frac{-2 \pm \sqrt{4 - 20}}{2}\)
Operamos: el cuadrado de 2 es 4 y el producto \(4 \cdot 1 \cdot 5 = 20\).
\(x = \frac{-2 \pm \sqrt{-16}}{2}\)
Restamos y vemos que el número dentro de la raíz es negativo (-16).
No existe \(\sqrt{-16}\)
Explicación: No hay ningún número real que al multiplicarlo por sí mismo dé negativo.
RESULTADO: Sin solución real.

2. INCOMPLETAS TIPO 1: a x2 + c = 0

Ejercicio Difícil: 3x2 - 48 = 0
3x2 = 48
Despejamos: pasamos el -48 al otro lado del igual como +48.
x2 = 48 / 3
El número 3 que multiplica a la x² pasa al otro lado dividiendo.
x2 = 16
Realizamos la división para simplificar el valor de x².
x = \(\pm \sqrt{16}\)
Para quitar el cuadrado, aplicamos la raíz cuadrada en el otro lado (recordando el ±).
x = 4, x = -4
Resolvemos la raíz. Obtenemos dos soluciones: una positiva y una negativa.
RESULTADO: x = 4, x = -4

3. INCOMPLETAS TIPO 2: a x2 + b x = 0

Ejercicio Difícil: 5x2 + 20x = 0
x · (5x + 20) = 0
Sacamos factor común "x" porque aparece en ambos términos.
x1 = 0
Primera solución: Para que el producto sea 0, la x de fuera debe ser 0.
5x + 20 = 0
Segunda solución: El paréntesis también puede ser igual a 0.
5x = -20 \implies x = -20 / 5
Despejamos la x del paréntesis pasando el 20 restando y el 5 dividiendo.
x2 = -4
Calculamos la división final para hallar la segunda solución.
RESULTADO: x = 0, x = -4
