📈 Análisis de Función: f(x) = (x+1) / (x-2)

Apuntes especiales para "El grupo que más habla de la academia"

1. El Dominio

Para que la función no explote, el denominador no puede ser cero. Lo igualamos para encontrar el valor prohibido:

x - 2 = 0 => x = 2

Dominio: D = ℝ \ {2}

2. Asíntotas y Límites

A) Asíntota Vertical (A.V.)

Se encuentra en el fallo del dominio (x=2). Estudiamos los límites laterales para saber hacia dónde se va el chisme:

  • Límite por la derecha: lim (x→2⁺) f(x) = 3 / 0⁺ = +∞
  • Límite por la izquierda: lim (x→2⁻) f(x) = 3 / 0⁻ = -∞

Hay una A.V. en x = 2.

B) Asíntota Horizontal (A.H.)

Miramos qué pasa cuando la x se vuelve loca (tiende a infinito):

lim (x→±∞) (x + 1) / (x - 2) = 1 / 1 = 1

Hay una A.H. en y = 1.

C) Asíntota Oblicua (A.O.)

⚠️ ¡Aviso para charlatanes! Como ya tenemos una Asíntota Horizontal, no perdáis el tiempo: no hay Oblicua.

3. Monotonía (¿Sube o baja?)

Realizamos la Primera Derivada siguiendo la regla del cociente:

f'(x) = [ 1 · (x-2) - (x+1) · 1 ] / (x-2)²
f'(x) = (x - 2 - x - 1) / (x-2)²
f'(x) = -3 / (x-2)²

Para ver el signo, usamos la recta numérica (sustituimos valores en f'(x)):

<----- (f' < 0) -----> (2) <----- (f' < 0) ----->
      ↘ DECRECE                ↘ DECRECE

Sustituimos por ejemplo x=0 (f'(0) = -3/4 < 0) y x=3 (f'(3) = -3/1 < 0).

4. Curvatura (¿Feliz o Triste?)

Calculamos la Segunda Derivada derivando el resultado anterior:

f''(x) = [ 0 · (x-2)² - (-3) · 2(x-2) ] / (x-2)⁴
f''(x) = 6(x-2) / (x-2)⁴
f''(x) = 6 / (x-2)³

Representamos en la recta y sustituimos en f''(x):

<----- (f'' < 0) -----> (2) <----- (f'' > 0) ----->
      ∩ CONVEXA                ∪ CÓNCAVA
