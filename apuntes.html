Ecuaciones de 2º Grado: Resolución Visual y Narrativa

1. ECUACIONES COMPLETAS: a x2 + b x + c = 0

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Ejemplo 1: Dos soluciones reales

Ejercicio: x2 - 5x + 6 = 0

\(a = 1, b = -5, c = 6\)
Identificamos los valores que acompañan a las letras y el número suelto.
\(x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 1 \cdot 6}}{2 \cdot 1}\)
Cambiamos las letras de la fórmula por nuestros números. ¡Ojo con el doble signo menos!
\(\sqrt{25 - 24} = \sqrt{1}\)
Calculamos el cuadrado y la multiplicación de dentro para restarlos.
\(x = \frac{5 \pm 1}{2}\)
Resolvemos la raíz y nos preparamos para sacar los dos caminos.
\(x_1 = 3, x_2 = 2\)
Sumamos por un lado (6/2) y restamos por otro (4/2) para obtener los resultados.
RESULTADO: x = 3, x = 2

Ejemplo 2: Una solución única

Ejercicio: x2 - 4x + 4 = 0

\(x = \frac{4 \pm \sqrt{16 - 16}}{2}\)
Sustituimos y operamos la potencia y la multiplicación.
\(x = \frac{4 \pm 0}{2}\)
Al restar el interior nos da cero. Sumar o restar cero no cambia nada.
RESULTADO ÚNICO: x = 2

Ejemplo 3: Sin solución real

Ejercicio: x2 + 2x + 5 = 0

\(\sqrt{4 - 20} = \sqrt{-16}\)
Calculamos el interior de la raíz y vemos que el resultado es negativo.

Explicación: No existe ningún número que multiplicado por sí mismo dé un valor negativo.

RESULTADO: Sin solución real.

2. INCOMPLETAS TIPO 1: a x2 + c = 0

Fácil: x2 - 9 = 0

x2 = 9
Pasamos el número al otro lado del igual cambiándole el signo.
x = \(\pm \sqrt{9}\)
Quitamos el cuadrado haciendo la raíz cuadrada del número.
RESULTADO: x = 3, x = -3

3. INCOMPLETAS TIPO 2: a x2 + b x = 0

Difícil: 3x2 - 12x = 0

3x · (x - 4) = 0
Sacamos "x" fuera porque está repetida en ambos términos.
3x = 0 \(\implies\) x = 0
La primera solución siempre es cero porque anula la x de fuera.
x - 4 = 0 \(\implies\) x = 4
La segunda solución sale de resolver el pequeño paréntesis que queda.
RESULTADO: x = 0, x = 4
