Ecuaciones de 2º Grado: Resolución Paso a Paso sin Saltos

1. Ecuaciones Completas: \(ax^2 + bx + c = 0\)

Para resolver estas ecuaciones usamos la Fórmula General. Es vital identificar bien los signos de a, b y c.
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

A. Caso con 2 Soluciones Reales

Ejercicio: \(x^2 - 5x + 6 = 0\)

Paso 1: Identificar coeficientes. a = 1 | b = -5 | c = 6 Paso 2: Sustituir en la fórmula. \(x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 1 \cdot 6}}{2 \cdot 1}\) Paso 3: Calcular el interior de la raíz (Discriminante). Potencia: \((-5)^2 = 25\) Multiplicación: \(4 \cdot 1 \cdot 6 = 24\) Resta: \(25 - 24 = 1\) Paso 4: Resolver la raíz y simplificar. \(x = \frac{5 \pm \sqrt{1}}{2} \implies x = \frac{5 \pm 1}{2}\) Paso 5: Separar los dos caminos (+ y -). Camino positivo: \(x_1 = \frac{5 + 1}{2} = \frac{6}{2} = 3\) Camino negativo: \(x_2 = \frac{5 - 1}{2} = \frac{4}{2} = 2\) RESULTADO: x = 3, x = 2

B. Caso con 1 Solución Única

Ejercicio: \(x^2 - 6x + 9 = 0\)

a = 1 | b = -6 | c = 9 \(x = \frac{-(-6) \pm \sqrt{(-6)^2 - 4 \cdot 1 \cdot 9}}{2 \cdot 1}\) Raíz: \(\sqrt{36 - 36} = \sqrt{0} = 0\) \(x = \frac{6 \pm 0}{2} = \frac{6}{2} = 3\) RESULTADO: x = 3 (Solución doble)

C. Caso Sin Solución

Ejercicio: \(x^2 + 2x + 5 = 0\)

a = 1 | b = 2 | c = 5 \(x = \frac{-2 \pm \sqrt{2^2 - 4 \cdot 1 \cdot 5}}{2 \cdot 1}\) Raíz: \(\sqrt{4 - 20} = \sqrt{-16}\) Como no existe la raíz de un número negativo en los números reales: RESULTADO: No tiene solución real.

2. Incompletas Tipo 1: \(ax^2 + c = 0\)

Se resuelven despejando la \(x^2\) como si fuera una ecuación normal y al final se hace la raíz.

Fácil

Ejercicio: \(x^2 - 25 = 0\)

1. Pasamos el 25 sumando: \(x^2 = 25\) 2. Hacemos raíz cuadrada: \(x = \pm \sqrt{25}\) RESULTADO: x = 5, x = -5

Difícil

Ejercicio: \(3x^2 - 48 = 0\)

1. Pasamos el 48: \(3x^2 = 48\) 2. El 3 pasa dividiendo: \(x^2 = \frac{48}{3}\) 3. Resolvemos división: \(x^2 = 16\) 4. Raíz: \(x = \pm \sqrt{16}\) RESULTADO: x = 4, x = -4

3. Incompletas Tipo 2: \(ax^2 + bx = 0\)

Se resuelven sacando Factor Común. Recuerda: una solución siempre es cero.

Fácil

Ejercicio: \(x^2 - 7x = 0\)

1. Sacamos x fuera: \(x \cdot (x - 7) = 0\) 2. Para que una multiplicación de cero, uno de los dos debe ser cero: Solución 1: x = 0 Solución 2: x - 7 = 0 \(\implies\) x = 7 RESULTADO: x = 0, x = 7

Difícil

Ejercicio: \(5x^2 + 20x = 0\)

1. Sacamos factor común (5x): \(5x \cdot (x + 4) = 0\) 2. Igualamos la primera parte: \(5x = 0 \implies x = \frac{0}{5} = 0\) 3. Igualamos la segunda: \(x + 4 = 0 \implies x = -4\) RESULTADO: x = 0, x = -4
