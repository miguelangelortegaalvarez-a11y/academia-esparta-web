Ecuaciones de 2º Grado: Teoría y Práctica Detallada

1. Ecuaciones Completas (\(ax^2 + bx + c = 0\))

Se utilizan todos los términos. Aplicamos la fórmula general y analizamos el discriminante (\(b^2 - 4ac\)) para saber cuántas soluciones hay.
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

A. Caso: Dos Soluciones Reales

Ejercicio: \(x^2 - 5x + 6 = 0\)
1. Identificamos: \(a=1, b=-5, c=6\).
2. Sustituimos: \(x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 1 \cdot 6}}{2 \cdot 1}\).
3. Resolvemos raíz: \(x = \frac{5 \pm \sqrt{25 - 24}}{2} = \frac{5 \pm \sqrt{1}}{2}\).
4. Separamos soluciones:
     \(x_1 = \frac{5+1}{2} = 3\) | \(x_2 = \frac{5-1}{2} = 2\).
Resultado: x = 3, x = 2

B. Caso: Una Solución Única (Doble)

Ejercicio: \(x^2 - 6x + 9 = 0\)
1. \(a=1, b=-6, c=9\).
2. \(x = \frac{6 \pm \sqrt{(-6)^2 - 4 \cdot 1 \cdot 9}}{2 \cdot 1}\).
3. Operamos: \(x = \frac{6 \pm \sqrt{36 - 36}}{2} = \frac{6 \pm 0}{2}\).
4. Como la raíz es 0, solo hay un camino.
Resultado: x = 3

C. Caso: Sin Solución Real

Ejercicio: \(x^2 + 2x + 5 = 0\)
1. \(a=1, b=2, c=5\).
2. \(x = \frac{-2 \pm \sqrt{2^2 - 4 \cdot 1 \cdot 5}}{2 \cdot 1}\).
3. Operamos: \(x = \frac{-2 \pm \sqrt{4 - 20}}{2} = \frac{-2 \pm \sqrt{-16}}{2}\).
4. La raíz de un número negativo no existe en los reales.
Resultado: No tiene solución real.

2. Incompletas Tipo 1 (\(ax^2 + c = 0\))

Falta la "x". Se resuelve despejando el término al cuadrado y aplicando raíz cuadrada.

Fácil

Ejercicio: \(x^2 - 25 = 0\)
1. Despejamos: \(x^2 = 25\).
2. Aplicamos raíz a ambos lados: \(x = \pm \sqrt{25}\).
Resultado: x = 5, x = -5

Difícil

Ejercicio: \(3x^2 - 48 = 0\)
1. Pasamos el número: \(3x^2 = 48\).
2. El 3 pasa dividiendo: \(x^2 = \frac{48}{3} = 16\).
3. Raíz: \(x = \pm \sqrt{16}\).
Resultado: x = 4, x = -4

3. Incompletas Tipo 2 (\(ax^2 + bx = 0\))

Falta el número solo. Se resuelve sacando factor común. Importante: Una solución siempre es \(x = 0\).

Fácil

Ejercicio: \(x^2 - 7x = 0\)
1. Factor común: \(x(x - 7) = 0\).
2. Igualamos a cero las dos partes:
     - Primera parte: \(x = 0\).
     - Segunda parte: \(x - 7 = 0 \implies x = 7\).
Resultado: x = 0, x = 7

Difícil

Ejercicio: \(5x^2 + 20x = 0\)
1. Factor común (podemos sacar \(5x\)): \(5x(x + 4) = 0\).
2. Igualamos:
     - \(5x = 0 \implies x = \frac{0}{5} = 0\).
     - \(x + 4 = 0 \implies x = -4\).
Resultado: x = 0, x = -4
