Matemáticas: Ecuaciones de 2º Grado (Completas)

MARTINA

1. La Estructura y la Fórmula

Toda ecuación de segundo grado completa tiene esta forma: \( ax^2 + bx + c = 0 \)

\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]
El Discriminante (\(\Delta\)): Es el valor dentro de la raíz (\( b^2 - 4ac \)).
  • Si es positivo: Hay 2 soluciones.
  • Si es cero: Hay 1 solución (doble).
  • Si es negativo: No hay solución real.

2. Caso 1: Dos Soluciones Reales

Ecuación: \( x^2 - 5x + 6 = 0 \)
1. Identificar: \( a = 1, b = -5, c = 6 \).
2. Sustituir: \( x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4(1)(6)}}{2(1)} \)
3. Operar: \( x = \frac{5 \pm \sqrt{25 - 24}}{2} = \frac{5 \pm \sqrt{1}}{2} = \frac{5 \pm 1}{2} \)
4. Resultados:
    \( x_1 = \frac{5+1}{2} = \mathbf{3} \) | \( x_2 = \frac{5-1}{2} = \mathbf{2} \)

3. Caso 2: Una Solución (Doble)

Ecuación: \( x^2 - 4x + 4 = 0 \)
1. Identificar: \( a = 1, b = -4, c = 4 \).
2. Sustituir: \( x = \frac{4 \pm \sqrt{(-4)^2 - 4(1)(4)}}{2} \)
3. Operar: \( x = \frac{4 \pm \sqrt{16 - 16}}{2} = \frac{4 \pm 0}{2} \)
4. Resultado: \( x = \frac{4}{2} = \mathbf{2} \) (Solución única).

4. Caso 3: Sin Solución Real

Ecuación: \( x^2 + 2x + 5 = 0 \)
1. Identificar: \( a = 1, b = 2, c = 5 \).
2. Sustituir: \( x = \frac{-2 \pm \sqrt{2^2 - 4(1)(5)}}{2} \)
3. Operar: \( x = \frac{-2 \pm \sqrt{4 - 20}}{2} = \frac{-2 \pm \sqrt{-16}}{2} \)
4. Conclusión: Como la raíz de un número negativo no existe en los reales, No tiene solución.
