⚔️ El Tiro del Espartano

Problema: Un alumno lanza un balón con trayectoria parabólica. Los datos son:
  • Posición del lanzador: a 2 metros de ti (tu posición es x=0).
  • Altura de lanzamiento: 1,30 metros.
  • Altura máxima (vértice): 3 metros, alcanzada a 2 metros del lanzador.
  • Objetivo: Canasta situada a 5,5 metros de ti y a 2 metros de altura.
¿Conseguirá encestar el alumno?

Desarrollo Paso a Paso

Paso 1: Identificar los puntos clave.
Tomando tu posición como el origen \( (0,0) \):

  • Punto de lanzamiento (A): \( (2, \ 1.3) \)
  • Punto de altura máxima (Vértice V): El lanzador está en \(x=2\) y el máximo ocurre 2m después, luego es en \(x=4\). Vértice: \( (4, \ 3) \)

Paso 2: Relación del Vértice.
En la forma general \( y = ax^2 + bx + c \), la coordenada \(x\) del vértice es \( x_v = \frac{-b}{2a} \).
Sustituyendo: \( 4 = \frac{-b}{2a} \implies -b = 8a \implies \mathbf{b = -8a} \).

Paso 3: Crear el sistema de ecuaciones.
Sustituimos los puntos A y V en la ecuación general:

  1. \( 1.3 = a(2)^2 + b(2) + c \implies 4a + 2b + c = 1.3 \)
  2. \( 3 = a(4)^2 + b(4) + c \implies 16a + 4b + c = 3 \)
Sustituimos \( b = -8a \) en ambas:
  • \( 4a + 2(-8a) + c = 1.3 \implies \mathbf{-12a + c = 1.3} \)
  • \( 16a + 4(-8a) + c = 3 \implies \mathbf{-16a + c = 3} \)

Paso 4: Resolver el sistema.
Restando las dos ecuaciones anteriores:
\( (-12a + c) - (-16a + c) = 1.3 - 3 \)
\( 4a = -1.7 \implies \mathbf{a = -0.425} \)

Calculamos \(b\): \( b = -8(-0.425) = \mathbf{3.4} \)
Calculamos \(c\): \( -12(-0.425) + c = 1.3 \implies 5.1 + c = 1.3 \implies \mathbf{c = -3.8} \)

Representación Gráfica

Sustituyendo \( x = 5.5 \) en la ecuación \( y = -0.425x^2 + 3.4x - 3.8 \):

\( y = 2.04375 \text{ metros} \)

¡ENCERSTADO! La pelota pasa por el centro del aro.
