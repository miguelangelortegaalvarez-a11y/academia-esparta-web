SOLUCIONARIO INTEGRAL (42 EJERCICIOS)

Nivel 1: Polinomios y Potencias

1. \(f(x) = 3x^5 - 4x^2 + 7x - 9\)
\(3(5x^4) - 4(2x) + 7(1) - 0\)
\(f'(x) = 15x^4 - 8x + 7\)
2. \(f(x) = \frac{1}{2}x^4 - \frac{2}{3}x^3 + 5\)
\(\frac{1}{2}(4x^3) - \frac{2}{3}(3x^2) + 0\)
\(f'(x) = 2x^3 - 2x^2\)
3. \(f(x) = x^{-3} + 4x^{-1}\)
\(-3x^{-4} + 4(-1)x^{-2}\)
\(f'(x) = -3x^{-4} - 4x^{-2} = -\frac{3}{x^4} - \frac{4}{x^2}\)
4. \(f(x) = 6x^2 - \sqrt{x}\)
\(12x - \frac{1}{2}x^{-1/2}\)
\(f'(x) = 12x - \frac{1}{2\sqrt{x}}\)
5. \(f(x) = \frac{4}{x^2} + 3x\)
\(4x^{-2} + 3x \rightarrow 4(-2x^{-3}) + 3\)
\(f'(x) = -\frac{8}{x^3} + 3\)
6. \(f(x) = 2x^6 - 5x^4 + \frac{x^2}{2}\)
\(2(6x^5) - 5(4x^3) + \frac{1}{2}(2x)\)
\(f'(x) = 12x^5 - 20x^3 + x\)
7. \(f(x) = \sqrt[3]{x} + x^2\)
\(x^{1/3} + x^2 \rightarrow \frac{1}{3}x^{-2/3} + 2x\)
\(f'(x) = \frac{1}{3\sqrt[3]{x^2}} + 2x\)
8. \(f(x) = \frac{1}{x^5} - x^{-2}\)
\(x^{-5} - x^{-2} \rightarrow -5x^{-6} - (-2)x^{-3}\)
\(f'(x) = -\frac{5}{x^6} + \frac{2}{x^3}\)
9. \(f(x) = \pi x^3 + e x\)
\(\pi(3x^2) + e(1)\)
\(f'(x) = 3\pi x^2 + e\)
10. \(f(x) = \frac{x^3 - 2x^2}{x}\)
Simplificamos: \(x^2 - 2x \rightarrow 2x - 2\)
\(f'(x) = 2x - 2\)
11. \(f(x) = 5\sqrt{x^3}\)
\(5x^{3/2} \rightarrow 5 \cdot \frac{3}{2}x^{1/2}\)
\(f'(x) = \frac{15}{2}\sqrt{x}\)
12. \(f(x) = (x+1)(x-1)\)
Simplificamos: \(x^2 - 1 \rightarrow 2x\)
\(f'(x) = 2x\)
13. \(f(x) = -x^8 + 12x^5 - x\)
\(-8x^7 + 12(5x^4) - 1\)
\(f'(x) = -8x^7 + 60x^4 - 1\)
14. \(f(x) = \frac{3}{4}x^4 - \frac{x^3}{6}\)
\(\frac{3}{4}(4x^3) - \frac{1}{6}(3x^2)\)
\(f'(x) = 3x^3 - \frac{x^2}{2}\)

Nivel 2: Productos y Cocientes

15. \(f(x) = (x^2+2)(x^3-1)\)
\((2x)(x^3-1) + (x^2+2)(3x^2)\)
\(f'(x) = 5x^4 + 6x^2 - 2x\)
16. \(f(x) = \frac{x+5}{x-2}\)
\(\frac{1(x-2) - (x+5)1}{(x-2)^2}\)
\(f'(x) = \frac{-7}{(x-2)^2}\)
17. \(f(x) = 3x^2 \cdot \sqrt{x}\)
\(3x^{5/2} \rightarrow 3 \cdot \frac{5}{2}x^{3/2}\)
\(f'(x) = \frac{15}{2}\sqrt{x^3}\)
18. \(f(x) = \frac{2x^2}{x^2+1}\)
\(\frac{4x(x^2+1) - (2x^2)(2x)}{(x^2+1)^2}\)
\(f'(x) = \frac{4x}{(x^2+1)^2}\)
19. \(f(x) = (x^4-3x)(2x+5)\)
\((4x^3-3)(2x+5) + (x^4-3x)2\)
\(f'(x) = 10x^4 + 20x^3 - 12x - 15\)
20. \(f(x) = \frac{x^2-4}{x+2}\)
Simplificamos: \(x-2 \rightarrow 1\)
\(f'(x) = 1\)
21. \(f(x) = \frac{1}{x^2-3x}\)
\(\frac{0 - (2x-3)}{(x^2-3x)^2}\)
\(f'(x) = \frac{3-2x}{(x^2-3x)^2}\)
22. \(f(x) = \sqrt{x}(x^2-1)\)
\(\frac{1}{2\sqrt{x}}(x^2-1) + \sqrt{x}(2x)\)
\(f'(x) = \frac{5x^2-1}{2\sqrt{x}}\)
23. \(f(x) = \frac{5x-2}{x^3}\)
\(\frac{5(x^3) - (5x-2)3x^2}{x^6}\)
\(f'(x) = \frac{6-10x}{x^4}\)
24. \(f(x) = (2x^3+x)(x^2-5)\)
\((6x^2+1)(x^2-5) + (2x^3+x)2x\)
\(f'(x) = 10x^4 - 27x^2 - 5\)
25. \(f(x) = \frac{\sqrt{x}}{x+1}\)
\(\frac{\frac{1}{2\sqrt{x}}(x+1) - \sqrt{x}}{(x+1)^2}\)
\(f'(x) = \frac{1-x}{2\sqrt{x}(x+1)^2}\)
26. \(f(x) = \frac{x^3+1}{x^3-1}\)
\(\frac{3x^2(x^3-1) - (x^3+1)3x^2}{(x^3-1)^2}\)
\(f'(x) = \frac{-6x^2}{(x^3-1)^2}\)
27. \(f(x) = x^2 \cdot \sqrt[3]{x^2}\)
\(x^{8/3} \rightarrow \frac{8}{3}x^{5/3}\)
\(f'(x) = \frac{8}{3}\sqrt[3]{x^5}\)
28. \(f(x) = \frac{x^2+3x+2}{x}\)
Simplificamos: \(x + 3 + 2x^{-1} \rightarrow 1 - 2x^{-2}\)
\(f'(x) = 1 - \frac{2}{x^2}\)

Nivel 3: Regla de la Cadena

29. \(f(x) = (x^2+3x)^4\)
\(4(x^2+3x)^3(2x+3)\)
\(f'(x) = (8x+12)(x^2+3x)^3\)
30. \(f(x) = \sqrt{5x^2-x}\)
\(\frac{10x-1}{2\sqrt{5x^2-x}}\)
\(f'(x) = \frac{10x-1}{2\sqrt{5x^2-x}}\)
31. \(f(x) = (4x-1)^{10}\)
\(10(4x-1)^9(4)\)
\(f'(x) = 40(4x-1)^9\)
32. \(f(x) = \sqrt[3]{x^3+8}\)
\(\frac{1}{3}(x^3+8)^{-2/3}(3x^2)\)
\(f'(x) = \frac{x^2}{\sqrt[3]{(x^3+8)^2}}\)
33. \(f(x) = \frac{1}{(x^2+1)^3}\)
\(-3(x^2+1)^{-4}(2x)\)
\(f'(x) = \frac{-6x}{(x^2+1)^4}\)
34. \(f(x) = (2x^2-5x+1)^2\)
\(2(2x^2-5x+1)(4x-5)\)
\(f'(x) = (8x-10)(2x^2-5x+1)\)
35. \(f(x) = \sqrt{\frac{x}{x+1}}\)
\(\frac{1}{2\sqrt{\frac{x}{x+1}}} \cdot \frac{1}{(x+1)^2}\)
\(f'(x) = \frac{1}{2(x+1)^2}\sqrt{\frac{x+1}{x}}\)
36. \(f(x) = (x^3-2)^{-5}\)
\(-5(x^3-2)^{-6}(3x^2)\)
\(f'(x) = \frac{-15x^2}{(x^3-2)^6}\)
37. \(f(x) = \sqrt[5]{(x^2+1)^2}\)
\(\frac{2}{5}(x^2+1)^{-3/5}(2x)\)
\(f'(x) = \frac{4x}{5\sqrt[5]{(x^2+1)^3}}\)
38. \(f(x) = (x + \sqrt{x})^3\)
\(3(x+\sqrt{x})^2(1 + \frac{1}{2\sqrt{x}})\)
\(f'(x) = 3(x+\sqrt{x})^2(1 + \frac{1}{2\sqrt{x}})\)
39. \(f(x) = \left(\frac{2x}{3x-1}\right)^2\)
\(2\left(\frac{2x}{3x-1}\right) \cdot \frac{-2}{(3x-1)^2}\)
\(f'(x) = \frac{-8x}{(3x-1)^3}\)
40. \(f(x) = \sqrt{1+\sqrt{x}}\)
\(\frac{1}{2\sqrt{1+\sqrt{x}}} \cdot \frac{1}{2\sqrt{x}}\)
\(f'(x) = \frac{1}{4\sqrt{x}\sqrt{1+\sqrt{x}}}\)
41. \(f(x) = (x^4 - 2x^2 + 5)^6\)
\(6(x^4 - 2x^2 + 5)^5(4x^3 - 4x)\)
\(f'(x) = (24x^3-24x)(x^4-2x^2+5)^5\)
42. \(f(x) = \frac{1}{\sqrt{x^2+4}}\)
\(-\frac{1}{2}(x^2+4)^{-3/2}(2x)\)
\(f'(x) = \frac{-x}{\sqrt{(x^2+4)^3}}\)
