ALEJANDRA - 2º ESO

La Herramienta Maestra

¡Atención Alejandra! Toda ecuación de segundo grado tiene la forma: \(ax^2 + bx + c = 0\).
Para vencerlas, utilizamos la Fórmula General:
\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

Ejemplo Paso a Paso

Resolver: \(x^2 - 5x + 6 = 0\)

1. Identificar coeficientes: \(a = 1, \quad b = -5, \quad c = 6\).

2. Sustituir en la fórmula:
\[ x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 1 \cdot 6}}{2 \cdot 1} \] \[ x = \frac{5 \pm \sqrt{25 - 24}}{2} = \frac{5 \pm \sqrt{1}}{2} \]
3. Calcular soluciones:
\(x_1 = \frac{5 + 1}{2} = \frac{6}{2} = \mathbf{3}\)
\(x_2 = \frac{5 - 1}{2} = \frac{4}{2} = \mathbf{2}\)
