Cálculo de Dominios: Nivel Avanzado

4º ESO

Reto 1: Función Racional de Grado 3

Regla de Oro: En las funciones fraccionarias, el denominador nunca puede ser cero. Debes igualar el denominador a 0 y quitar esos valores de \(\mathbb{R}\).
Calcula el dominio de: \[ f(x) = \frac{2x - 5}{x^3 - 4x^2 + x + 6} \]
Pista Espartana: 1. Igualar el denominador a 0.
2. Como es de grado 3, usa Ruffini para encontrar la primera raíz.
3. Usa la Ecuación de 2º Grado para las raíces restantes.

Reto 2: Logaritmo en el Denominador

Doble Restricción:
1. El argumento del logaritmo debe ser positivo (\(> 0\)).
2. El denominador no puede ser 0 (recuerda que \(\log(1) = 0\)).
Calcula el dominio de: \[ g(x) = \frac{x + 1}{\log(x - 4)} \]
Pista Espartana: 1. ¿Cuándo existe el logaritmo? Resuelve la inecuación \(x - 4 > 0\).
2. ¿Cuándo se hace 0 el denominador? Resuelve \(\log(x - 4) = 0\).
