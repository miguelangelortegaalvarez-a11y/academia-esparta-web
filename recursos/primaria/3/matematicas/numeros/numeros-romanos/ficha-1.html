Se leen de izquierda a derecha. Si una letra está a la derecha de otra mayor o igual, se suma (VI = 5+1 = 6). Si está a la izquierda de una mayor, se resta (IV = 5−1 = 4). Una letra no se repite más de 3 veces seguidas.
