Sufijos para adjetivos · -oso, -able/-ible, -al
Sufijos que forman adjetivos
Algunos sufijos forman adjetivos a partir de nombres o verbos. El adjetivo resultante describe una cualidad o posibilidad.
-oso / -osa
-able / -ible
-al
-udo / -uda
¿Qué aporta cada sufijo de adjetivo?
-oso/-osa → «que tiene mucho de algo»: miedo+oso = miedoso · cariño+so = cariñoso · lluvio+so = lluvioso · famoso · sabroso

-able/-ible → «que puede ser / que merece ser»: lav+able = lavable · comest+ible = comestible · amable · terrible · adorable · invisible

-al → «relativo a, propio de»: nacion+al = nacional · natural · musical · cultural · especial

-udo/-uda → «que tiene en abundancia»: barba → barbudo · pelo → peludo · fuerza → forzudo
miedo + -oso → miedoso
cariño + -oso → cariñoso
lavar + -able → lavable
comer + -ible → comestible
nación + -al → nacional
música + -al → musical
barba + -udo → barbudo
pelo + -udo → peludo
miedo + -oso → miedoso
Raíz miedo + sufijo -oso → que tiene mucho miedo (adjetivo).
→ El sufijo -oso indica «que tiene mucho de algo».
lavar + -able → lavable
Raíz lavar + sufijo -able → que puede lavarse (adjetivo).
→ El sufijo -able/-ible indica posibilidad.
💡 Recuerda: -able o -ible
Usa -able con verbos en -ar: lavar → lavable, adorar → adorable.
Usa -ible con verbos en -er / -ir: comer → comestible, dividir → divisible.
(Hay excepciones, pero esta regla funciona la mayoría de las veces.)
