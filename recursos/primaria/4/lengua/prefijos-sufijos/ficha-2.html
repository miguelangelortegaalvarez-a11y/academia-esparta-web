Más prefijos: sub-, pre-, bi-/tri-, anti-
Cuatro prefijos de uso frecuente
Estos prefijos nos ayudan a entender el significado de muchas palabras de uso diario. Observa qué añade cada uno.
sub-
pre-
bi- / tri-
anti-
¿Qué significa cada prefijo?
sub- (debajo de / inferior): sub+marino = submarino · sub+director = subdirector · sub+suelo = subsuelo

pre- (antes de / delante): pre+histórico = prehistórico · pre+escolar = preescolar · pre+calentamiento = precalentamiento

bi-/tri- (dos / tres): bi+ciclo = bicicleta · bi+lingüe = bilingüe · tri+ángulo = triángulo · tri+ciclo = triciclo

anti- (contra): anti+biótico = antibiótico · anti+deslizante = antideslizante · anti+virus = antivirus
sub + marino → submarino
sub + director → subdirector
pre + histórico → prehistórico
pre + escolar → preescolar
bi + lingüe → bilingüe
tri + ángulo → triángulo
anti + biótico → antibiótico
anti + virus → antivirus
submarino
Prefijo sub- (debajo) + marino → que va bajo el mar.
→ El prefijo sub- indica posición inferior o «debajo de».
bilingüe
Prefijo bi- (dos) + lengua → que habla dos lenguas.
→ El prefijo bi- indica «dos».
💡 La familia de los números
tri- = tres: triángulo (tres ángulos), triciclo (tres ruedas), tricolor (tres colores).
Amplía: cuadri- = cuatro · penta- = cinco · hexa- = seis.
