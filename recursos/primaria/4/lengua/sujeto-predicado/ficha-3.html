El sujeto omitido (o tácito)
¿Qué es el sujeto omitido?
A veces el sujeto no aparece escrito en la oración, pero podemos saber quién realiza la acción gracias a la terminación del verbo. Ese sujeto que no se escribe se llama sujeto omitido o tácito.
¿Cómo sabemos quién es el sujeto omitido?
Mira la terminación del verbo. Cada terminación indica una persona:
-o → yo  (como, estudio, llego)
-mos → nosotros/as  (comemos, llegamos)
-s → tú  (comes, estudias, llegas)
-áis / -éis → vosotros/as  (coméis, llegáis)
-a / -e → él, ella  (come, llega)
-an / -en → ellos, ellas  (comen, llegan)
Llegamos tarde al colegio.
El verbo llegamos termina en -mos → sujeto omitido: (nosotros).
Prueba: si cambio llegamos → llegan, el sujeto pasaría a ser ellos. Confirma que el sujeto de llegamos es nosotros.
→ Sujeto omitido: (nosotros) · Predicado: llegamos tarde al colegio.
¿Estudiáis mucho en casa?
El verbo estudiáis termina en -áis → sujeto omitido: (vosotros).
→ Sujeto omitido: (vosotros) · Predicado: ¿estudiáis mucho en casa?
💡 Recuerda
El sujeto omitido o tácito no está escrito, pero el verbo nos dice quién es. Podemos escribirlo entre paréntesis para mostrarlo: Comemos en el jardín. → (Nosotros) comemos en el jardín.
