Álgebra: Introducción

El Álgebra es la parte de las matemáticas que utiliza letras, números y signos para expresar operaciones generales. Es como un lenguaje para "traducir" frases de la vida real a cálculos matemáticos.

1. Lenguaje Algebraico

Usamos letras (normalmente la \(x\), la \(y\) o la \(a\)) para representar números que no conocemos.

  • Un número cualquiera: \(x\)
  • El doble de un número: \(2x\)
  • El triple de un número: \(3x\)
  • Un número más cinco: \(x + 5\)
  • El cuadrado de un número: \(x^2\)

2. Expresiones Algebraicas

Es una combinación de números y letras unidos por los signos de las operaciones.

Ejemplo: \(3x^2 + 5x - 2\)

3. Los Monomios

Un monomio es la expresión más simple, formada por el producto de un número y una letra.

Monomio: 5x³
  • Coeficiente: El número (en este caso, 5).
  • Parte literal: La letra con su exponente (en este caso, x³).
  • Grado: El exponente de la letra (en este caso, 3).

4. Operaciones con Monomios

Suma y Resta: Solo se pueden sumar o restar si tienen la misma parte literal (se llaman monomios semejantes).

\(3x + 2x = 5x\) ✅

\(5x + 2y\) ❌ (No se puede sumar)
