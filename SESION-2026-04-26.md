## Cómo continuar en la próxima sesión

### Paso 1 — Clonar / actualizar el repo (si no está en local)
```bash
cd /tmp
git clone https://github.com/miguelangelortegaalvarez-a11y/academia-esparta-web.git academia-esparta-repo
```
Si ya existe:
```bash
cd /tmp/academia-esparta-repo
git pull
```

### Paso 2 — Subir cambios a GitHub
```bash
cd /tmp/academia-esparta-repo
git add <archivo>
git commit -m "mensaje"
git push https://<TOKEN>@github.com/miguelangelortegaalvarez-a11y/academia-esparta-web.git main
```
> El token de GitHub hay que pedírselo al usuario cada sesión (caduca). El usuario lo tiene en su cuenta de GitHub → Settings → Developer settings → Personal access tokens.

### Paso 3 — Primera tarea al retomar
1. Confirmar que ficha-1 cabe en un folio (el usuario debe abrirla y darle a imprimir)
2. Si hay correcciones, aplicarlas
3. Si está bien, crear la **ficha 2: Sonido inicial**
