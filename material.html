BLOQUE I

Derivadas elementales · ejercicios resueltos

01/13
Derivada de una constante

La derivada de cualquier número es cero

\(y = k\) ⟹ \(y' = 0\)
Ejemplos resueltos
Ejemplo 1
\(y = 7\)

7 es un número fijo, no depende de \(x\).

y' = 0
Ejemplo 2
\(y = -\pi\)

\(-\pi\) sigue siendo una constante.

y' = 0
Ejemplo 3
\(y = \sqrt{5}\)

Aunque tenga raíz, es un número.

y' = 0
02/13
Función identidad

La derivada de \(x\) vale siempre 1

\(y = x\) ⟹ \(y' = 1\)
Ejemplos resueltos
Ejemplo 1
\(f(x) = x\)

Caso directo de la regla.

f'(x) = 1
Ejemplo 2
\(y = x + 4\)

Derivada de \(x\) = 1; derivada de \(4\) = 0.

y' = 1
03/13
Regla de la potencia

Baja el exponente y resta uno

\(y = x^{n}\) ⟹ \(y' = n\,x^{n-1}\)
Ejemplos resueltos
Ejemplo 1
\(y = x^{3}\)

Baja el 3 y deja \(x^{3-1} = x^{2}\).

y' = \(3x^{2}\)
Ejemplo 2
\(y = x^{5}\)

Baja el 5; el exponente queda \(x^{4}\).

y' = \(5x^{4}\)
Ejemplo 3
\(y = x^{-2}\)

Baja \(-2\); exponente \(-2-1=-3\).

y' = \(-2x^{-3}\)

BLOQUE II

Reglas de operación · ejercicios resueltos

04/13
Suma o resta

Se deriva término a término

\(y = f \pm g\) ⟹ \(y' = f' \pm g'\)
Ejemplos resueltos
Ejemplo 1
\(y = 3x^{2} + 5x - 1\)

Derivada de \(3x^{2}\) = \(6x\)

Derivada de \(5x\) = \(5\)

Derivada de \(-1\) = \(0\)

y' = \(6x + 5\)
Ejemplo 2
\(y = x^{4} - 2x^{2} + 7\)

\(x^{4}\) → \(4x^{3}\)

\(-2x^{2}\) → \(-4x\)

\(+7\) → \(0\)

y' = \(4x^{3} - 4x\)
05/13
Constante por función

El número se queda multiplicando

\(y = k\,f(x)\) ⟹ \(y' = k\,f'(x)\)
Ejemplos resueltos
Ejemplo 1
\(y = 7x^{4}\)

Derivada de \(x^{4}\) = \(4x^{3}\).

El 7 se mantiene: \(7\cdot 4x^{3}\).

y' = \(28x^{3}\)
Ejemplo 2
\(y = -5x^{2}\)

Derivada de \(x^{2}\) = \(2x\).

\(-5 \cdot 2x = -10x\).

y' = \(-10x\)

BLOQUE II

Producto y cociente · ejercicios resueltos

06/13
Regla del producto

Derivada del primero por el segundo + el primero por la derivada del segundo

\(y = f\cdot g\) ⟹ \(y' = f'\,g + f\,g'\)
Ejemplos resueltos
Ejemplo 1
\(y = x^{2}\,(3x+1)\)

\(f = x^{2}\) → \(f' = 2x\)

\(g = 3x+1\) → \(g' = 3\)

\(y' = 2x(3x+1) + x^{2}\cdot 3\)

\(= 6x^{2} + 2x + 3x^{2}\)

y' = \(9x^{2} + 2x\)
Ejemplo 2
\(y = (x+1)(x^{2}-x)\)

\(f = x+1\) → \(f' = 1\)

\(g = x^{2}-x\) → \(g' = 2x-1\)

\(y' = 1\cdot(x^{2}-x) + (x+1)(2x-1)\)

\(= x^{2}-x + 2x^{2}+x-1\)

y' = \(3x^{2} - 1\)
07/13
Regla del cociente

Cuidado con el orden y con elevar al cuadrado el denominador

\(y = \dfrac{f}{g}\) ⟹ \(y' = \dfrac{f'g - fg'}{g^{2}}\)
Ejemplos resueltos
Ejemplo 1
\(y = \dfrac{2x+1}{x-3}\)

\(f = 2x+1\) → \(f' = 2\)

\(g = x-3\) → \(g' = 1\)

Numerador: \(2(x-3) - (2x+1)\cdot 1\)

\(= 2x-6-2x-1 = -7\)

y' = \(\dfrac{-7}{(x-3)^{2}}\)
Ejemplo 2
\(y = \dfrac{x^{2}}{x+1}\)

\(f = x^{2}\) → \(f' = 2x\)

\(g = x+1\) → \(g' = 1\)

Numerador: \(2x(x+1) - x^{2}\)

\(= 2x^{2}+2x-x^{2} = x^{2}+2x\)

y' = \(\dfrac{x^{2}+2x}{(x+1)^{2}}\)

BLOQUE III

Regla de la cadena · ejercicios resueltos

08/13
Potencia compuesta

Deriva la potencia y multiplica por la derivada de dentro

\(y = [f(x)]^{a}\) ⟹ \(y' = a\,[f(x)]^{a-1}\,f'(x)\)
Ejemplos resueltos
Ejemplo 1
\(y = (3x+2)^{5}\)

\(f = 3x+2\) → \(f' = 3\)

Aplica la regla: \(5(3x+2)^{4}\cdot 3\)

y' = \(15\,(3x+2)^{4}\)
Ejemplo 2
\(y = (x^{2}-1)^{4}\)

\(f = x^{2}-1\) → \(f' = 2x\)

\(4(x^{2}-1)^{3}\cdot 2x\)

y' = \(8x\,(x^{2}-1)^{3}\)
09/13
Raíz cuadrada

Numerador: derivada de dentro · Denominador: 2 por la raíz

\(y = \sqrt{f(x)}\) ⟹ \(y' = \dfrac{f'(x)}{2\sqrt{f(x)}}\)
Ejemplos resueltos
Ejemplo 1
\(y = \sqrt{x^{2}+1}\)

\(f = x^{2}+1\) → \(f' = 2x\)

Aplica: \(\dfrac{2x}{2\sqrt{x^{2}+1}}\)

Simplifica el 2.

y' = \(\dfrac{x}{\sqrt{x^{2}+1}}\)
Ejemplo 2
\(y = \sqrt{3x-2}\)

\(f = 3x-2\) → \(f' = 3\)

\(\dfrac{3}{2\sqrt{3x-2}}\)

y' = \(\dfrac{3}{2\sqrt{3x-2}}\)

BLOQUE IV

Logaritmos · ejercicios resueltos

10/13
Logaritmo neperiano

Derivada de dentro partido por lo de dentro

\(y = \ln f(x)\) ⟹ \(y' = \dfrac{f'(x)}{f(x)}\)
Ejemplos resueltos
Ejemplo 1
\(y = \ln(x^{2}+1)\)

\(f = x^{2}+1\) → \(f' = 2x\)

y' = \(\dfrac{2x}{x^{2}+1}\)
Ejemplo 2
\(y = \ln(3x)\)

\(f = 3x\) → \(f' = 3\)

\(\dfrac{3}{3x}\). Simplifica.

y' = \(\dfrac{1}{x}\)
11/13
Logaritmo en base \(a\)

Como el neperiano, pero multiplicando \(\ln a\) abajo

\(y = \log_{a} f(x)\) ⟹ \(y' = \dfrac{f'(x)}{f(x)\,\ln a}\)
Ejemplos resueltos
Ejemplo 1
\(y = \log_{2} x\)

\(f = x\) → \(f' = 1\)

y' = \(\dfrac{1}{x\,\ln 2}\)
Ejemplo 2
\(y = \log_{3}(2x+1)\)

\(f = 2x+1\) → \(f' = 2\)

y' = \(\dfrac{2}{(2x+1)\,\ln 3}\)

BLOQUE IV

Exponenciales · ejercicios resueltos

12/13
Exponencial natural

El \(e^{f}\) se queda igual; multiplicas por la derivada del exponente

\(y = e^{f(x)}\) ⟹ \(y' = e^{f(x)}\cdot f'(x)\)
Ejemplos resueltos
Ejemplo 1
\(y = e^{2x}\)

\(f = 2x\) → \(f' = 2\)

y' = \(2\,e^{2x}\)
Ejemplo 2
\(y = e^{x^{2}+1}\)

\(f = x^{2}+1\) → \(f' = 2x\)

y' = \(2x\,e^{x^{2}+1}\)
13/13
Exponencial en base \(a\)

Como la natural, pero apareciendo \(\ln a\) multiplicando

\(y = a^{f(x)}\) ⟹ \(y' = a^{f(x)}\cdot \ln a \cdot f'(x)\)
Ejemplos resueltos
Ejemplo 1
\(y = 2^{x}\)

\(f = x\) → \(f' = 1\)

y' = \(2^{x}\,\ln 2\)
Ejemplo 2
\(y = 3^{x^{2}}\)

\(f = x^{2}\) → \(f' = 2x\)

y' = \(2x\,\ln 3\,\cdot 3^{x^{2}}\)
