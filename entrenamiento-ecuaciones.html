SISTEMA DE PARTIDA 24:

{ x + y = 126
{ 1.14x = 0.75y

A continuación, desglosamos la estrategia paso a paso para resolver este problema de compras:

1. EL AISLAMIENTO ESTRATÉGICO

Buscamos la incógnita más sencilla de despejar. En la primera ecuación, dejamos la y sola pasando la x restando al otro lado:

y = 126 - x
2. LA SUSTITUCIÓN

Tomamos la segunda ecuación y reemplazamos la y por nuestra expresión entre paréntesis:

1.14x = 0.75 · (126 - x)
3. RESOLUCIÓN CON LIMPIEZA

Multiplicamos el paréntesis y agrupamos las x para hallar el precio del pantalón:

1.14x = 94.5 - 0.75x ⇒ 1.89x = 94.5 ⇒ x = 50
4. HALLAR PAREJA

Sustituimos x en el primer despeje para hallar el precio de los zapatos:

y = 126 - 50 = 76 ⇒ y = 76

SISTEMA DE PARTIDA 25:

{ x + y = 50
{ 4x - 3y = 116

Resolvemos el sistema correspondiente al test de aciertos (x) y errores (y):

1. EL DESPEJE

Despejamos la y en la ecuación del total de preguntas:

y = 50 - x
2. SUSTITUCIÓN DE VALORES

Llevamos este valor a la ecuación de los puntos totales:

4x - 3 · (50 - x) = 116
3. CÁLCULO DE ACIERTOS

Operamos el paréntesis y despejamos la x:

4x - 150 + 3x = 116 ⇒ 7x = 266 ⇒ x = 38
4. CÁLCULO DE ERRORES

Hallamos y restando los aciertos al total:

y = 50 - 38 = 12 ⇒ y = 12

SISTEMA DE PARTIDA 26:

{ x = 3y
{ x + 15 = 2(y + 15)

Calculamos las edades actuales de Carmen (x) y Maite (y):

1. SUSTITUCIÓN DIRECTA

Como ya tenemos x despejada (x=3y), sustituimos directamente en la segunda ecuación:

3y + 15 = 2 · (y + 15)
2. ELIMINACIÓN DE PARÉNTESIS

Multiplicamos el 2 por todo el bloque de la derecha:

3y + 15 = 2y + 30
3. HALLAR EDAD DE MAITE

Agrupamos las y a la izquierda:

3y - 2y = 30 - 15 ⇒ y = 15
4. HALLAR EDAD DE CARMEN

Multiplicamos por 3 la edad de Maite:

x = 3 · (15) = 45 ⇒ x = 45
